# Lyra Music — 定稿需求（v1.0，2026-11-11）

目标设备：vivo X100s Pro（OriginOS 4 / Android 14，天玑 9300+）。最低 Android 10（API 29），目标 Android 15（API 35）。
开发方式：原生 Kotlin + Jetpack Compose + Media3。开源（GPL-3.0），GitHub Actions 自动构建 APK，侧载安装，不上架应用商店。

---

## 0. 最高优先级：音质策略

**原则：解码 → 输出之间，App 不引入任何损失；一切会改变波形的处理默认旁路。**

| 环节 | 做法 |
|---|---|
| 解码 | 以源文件原始位深/采样率输出 PCM（float 内部表示，避免 16-bit 截断）。不在 App 内重采样、不做增益、不做抖动。 |
| 音量 | 使用系统音量（AudioTrack 不做软件缩放）。ReplayGain 为可选功能，默认关。 |
| DSP 链（EQ / 音调 / 速度 / 声道合并 / 淡入淡出） | 全部默认关闭。关闭时 AudioProcessor 链为空，PCM 直通 AudioTrack。任一打开后 UI 显示「DSP 已启用」标识。 |
| 输出 | Android 14+ 且连接 USB DAC 时，调用 `AudioManager.setPreferredMixerAttributes` 申请 bit-perfect 直通。内置扬声器 / 模拟输出经系统混音器（系统行为，App 无法绕过），UI 在「音频信息」页如实显示当前输出链路和采样率。 |
| 蓝牙 | 蓝牙编码（SBC/AAC/aptX/LDAC/LHDC）天然有损，App 只保证蓝牙编码器之前的 PCM 无损。 |
| 元数据写回 | 只改标签区，不触碰音频帧。写回后做校验（重新读取标签 + 音频流长度一致）。 |
| 非破坏性编辑 | EQ/音调/声道合并等按歌曲保存为参数，原文件不动。如需「导出处理后文件」走单独功能，生成新文件，原文件保留。 |

## 1. 音频格式

- 原生（Media3）：MP3、AAC/M4A、FLAC、WAV、OGG Vorbis、Opus、AMR、ALAC（容器支持时）。
- FFmpeg 扩展（CI 编译，arm64-v8a）：APE、WavPack、DSD（DSF/DFF，转 PCM 播放）、TTA、Musepack、WMA、AIFF、ALAC。
- CUE 分轨（整轨 FLAC/APE/WAV + .cue）。
- 无缝播放（gapless）。
- 显示源文件：格式、位深、采样率、码率、声道数，以及实际输出采样率。

## 2. 本地曲库

- 扫描：MediaStore 主扫描 + 自选文件夹（SAF）+ 增量扫描 + 黑名单文件夹 + 最短时长过滤。
- 标签：ID3v1/v2、Vorbis Comment、APE Tag、MP4 atom；内嵌封面；同目录 `cover.jpg / folder.jpg / front.jpg`；外挂 `.lrc`。
- 视图：歌曲 / 专辑 / 艺术家 / 专辑艺术家 / 文件夹 / 流派 / 年份 / 歌单 / 收藏 / 最近播放 / 最常播放。
- 搜索：标题/艺术家/专辑，支持拼音全拼与首字母。
- 排序：标题、艺术家、专辑、时长、添加时间、播放次数、文件大小。
- **流派**：
  - 自动：优先文件标签 → 其次在线元数据（MusicBrainz tags / 网易云 / QQ）→ 否则「未知」。
  - 手动：从内置流派列表（ID3v1 标准 + 华语常用：流行、摇滚、民谣、古风、说唱、电子、古典、爵士、R&B、轻音乐、影视原声、纯音乐、儿歌、戏曲、广播剧…）选择，也可新增自定义流派。手动修改可选同步写回文件标签。
- **删除**：两种方式明确区分
  - 「从 Lyra 移除」：只从数据库/歌单移除，文件保留，文件夹加入黑名单或单曲忽略。
  - 「从手机删除文件」：真正删除文件，二次确认（显示文件路径与大小），Android 11+ 走 `MediaStore.createDeleteRequest` 或在已授予「所有文件访问」时直接删除并通知 MediaStore。
- **文件自动整理**（可选，默认关）：规则模板 `{Music}/{AlbumArtist}/{Album}/{Track:02} - {Title}.{ext}`，模板可编辑；先预览「将移动 N 个文件」再执行；移动后更新 MediaStore 与数据库；冲突文件不覆盖并记录日志；支持撤销（保留 30 天移动日志）。

## 3. 播放

- 播放/暂停、上一首/下一首、进度拖动、±10s、播放模式（顺序 / 列表循环 / 单曲循环 / 随机不重复）。
- 播放队列：查看、拖拽排序、下一首播放、移除、清空、保存为歌单。
- 睡眠定时器（分钟 / N 首后）。
- 音频焦点：来电/导航 ducking 或暂停并自动恢复；耳机拔出、蓝牙断开自动暂停；蓝牙重连可选自动续播。
- 进程被杀 / 重启后恢复上次队列与进度。
- 前台服务 + OriginOS 后台白名单引导页。

## 4. 音效编辑器（统一入口，整合 EQ + 音调 + 声道）

一个「音效编辑器」页面，分三个 Tab，全部**非破坏性**、按歌曲或全局保存，默认全关：

1. **均衡器**：10 段图形 EQ + 前置增益 + 预设（平坦/流行/摇滚/古典/人声…）+ 自定义预设保存；低音增强；响度均衡（ReplayGain）。
2. **音调/速度**：音调 ±12 半音（0.5 半音步进），速度 0.5×–2.0×，可锁定音调改速度或锁定速度改音调。
3. **声道**：显示源文件声道数；选项：原样 / 合并为单声道（L+R 平均）/ 仅左 / 仅右 / 左右交换 / 多声道下混为立体声。立体声平衡滑块。

每首歌可「使用全局设置」或「本曲单独设置」。提供「导出为新文件」按钮（将当前 DSP 结果离线渲染成 FLAC/WAV 新文件，原文件不动）。

## 5. 歌词

- 来源优先级：内嵌（USLT/SYLT/LYRICS 标签）→ 同名 `.lrc` → 在线 → 无。
- 格式：标准 LRC（含 `[offset:]`、多时间戳行）、增强 LRC（逐字）、纯文本、双语（原文+翻译）。
- 显示：播放页滚动、当前行高亮、**点击任意行跳转**、偏移微调 ±0.1s 步进、字号/对齐/字体设置、横屏适配。
- 桌面悬浮歌词（悬浮窗权限）、锁屏/通知歌词。
- 歌词编辑器：手动修改文本、调整时间轴、另存为 .lrc。

## 6. 封面与歌曲信息

- 封面来源：内嵌 → 目录文件 → 在线。手动从相册更换、裁剪。
- 歌曲信息页：全部标签字段可编辑（标题、艺术家、专辑、专辑艺术家、作曲、作词、年份、音轨号/总数、碟号、流派、注释、歌词），保存时写回文件标签（可选）。
- 技术信息：格式、位深、采样率、码率、声道、时长、文件大小、路径、MD5。

## 7. 歌单

- 创建 / 重命名 / 删除 / 封面 / 描述；添加 / 移除 / 拖拽排序 / 批量操作。
- 收藏（♥）、最近播放、最常播放、播放历史。
- 导入 / 导出：M3U/M3U8、CSV（TuneMyMusic 格式：Track name, Artist name, Album, Playlist name, Type, ISRC, Spotify/Apple id）、JSON（Lyra 完整格式）。
- 导入时按「标题+艺术家」模糊匹配本地曲库，未匹配项列出供手动匹配。

## 8. 蓝牙与外部控制

- Media3 `MediaSession`：蓝牙耳机按键（单击/双击/三击）、车机 AVRCP 曲名/艺术家/专辑/封面/进度、通知栏与锁屏控件。
- 蓝牙设备名显示、当前蓝牙编码显示（可获取时）。
- 本版不做 Android Auto / Wear OS。

## 9. 在线元数据补全

### 9.1 触发
- 自动：扫描后发现缺失标题 / 艺术家 / 专辑 / 封面 / 歌词任一项（可在设置中选择「仅 Wi-Fi 自动」「手动」「关闭」）。
- 手动：单曲或批量选择「识别」。

### 9.2 第一步：自动识别（按置信度排序，取最优）
1. 音频指纹：Chromaprint → AcoustID → MusicBrainz Recording。
2. 已有部分标签：标题+艺术家 → MusicBrainz / 网易云 / QQ 音乐搜索。
3. 文件名解析：`艺术家 - 歌名`、`01. 歌名`、`歌名 (Live)` 等模式。
4. 时长匹配：候选时长与本地时长差 >3s 降权。

置信度 ≥ 0.85 自动应用；0.6–0.85 标记「待确认」；<0.6 不应用。

### 9.3 第二步：用户不满意 → 扩展搜索
- 结果页提供「换一个 / 扩展搜索」：用户可编辑搜索词（标题、艺术家、专辑），选择来源（全部 / MusicBrainz / 网易云 / QQ 音乐 / LRCLIB / Last.fm），展示候选列表（封面缩略图、标题、艺术家、专辑、时长、来源）。
- 用户可对每个字段单独选择采用哪个来源（例如封面用 QQ 的、歌词用网易云的、流派用 MusicBrainz 的）。
- 应用前显示「变更前 / 变更后」对比。

### 9.4 数据源
| 来源 | 用途 | 性质 |
|---|---|---|
| AcoustID + Chromaprint | 指纹识别 | 官方 |
| MusicBrainz + Cover Art Archive | 元数据、封面、流派 | 官方 |
| LRCLIB | 歌词（同步/纯文本） | 官方开源 |
| Last.fm | 标签/流派、艺术家图 | 官方（需 Key） |
| 网易云音乐 | 华语元数据、歌词（含翻译）、封面 | 非官方接口 |
| QQ 音乐 | 华语元数据、歌词、封面 | 非官方接口 |

非官方接口做成可插拔 Provider，接口失效时静默降级，不影响其他来源。

### 9.5 安全策略（针对非官方接口与下载内容）
- 只下载三类数据：JSON 文本、歌词文本、封面图片。**永远不下载、不执行任何可执行内容**（无 APK、无 dex、无 so、无脚本），App 内不使用 `DexClassLoader`、不使用 WebView 加载远程页面。
- 严格 HTTPS；证书由系统信任库校验，不允许用户导入自签证书；OkHttp 禁用明文流量（`cleartextTrafficPermitted=false`）。
- 响应大小上限：JSON ≤ 2 MB，歌词 ≤ 512 KB，封面 ≤ 15 MB；超限直接丢弃。
- JSON 用 kotlinx.serialization 严格模式解析，忽略未知字段，字段白名单映射，不使用反射型反序列化。
- 歌词 / 标签文本：去除控制字符、限制长度（单字段 ≤ 4 KB，歌词 ≤ 64 KB），写入文件前转义，不解释任何标记语言。
- 封面图片：先用 `BitmapFactory.Options.inJustDecodeBounds` 检查尺寸（≤ 8000×8000）再解码；以 Android `ImageDecoder` 解码（系统沙箱化解码器）；重新编码为 JPEG/PNG 后再写入文件标签（剥离原始容器中的任何额外数据块 / EXIF / 嵌入内容）。
- 网络请求在独立协程作用域，带超时（连接 10s / 读取 20s）与限速（AcoustID 3 req/s，MusicBrainz 1 req/s）。
- 非官方接口的请求参数只包含搜索词与歌曲时长，不发送设备标识、不发送用户曲库清单、不登录账号、不存储任何 Cookie。
- 所有在线获取的数据先进「待应用缓存」，经置信度门槛或用户确认后才写入数据库 / 文件。
- 应用层最小权限：不申请电话、短信、通讯录、位置、相机权限。
- 发布 APK 开启 R8 混淆、`android:allowBackup` 走受控备份规则、`debuggable=false`、`usesCleartextTraffic=false`。

### 9.6 写入
- 写入数据库（必做）+ 写回文件标签（默认开，可关）。
- 写回使用 jaudiotagger；写前备份标签区到数据库，可一键恢复原始标签。
- Android 11+ 申请「所有文件访问」（`MANAGE_EXTERNAL_STORAGE`，侧载允许）；未授予时回退到 `MediaStore.createWriteRequest` 逐文件授权。

## 10. 备份 / 恢复 / 迁移（对标 TuneMyMusic）

- 导出：歌单（M3U / CSV / JSON）、收藏、播放记录、元数据修正记录、DSP 设置、应用设置 → 单个 `.lyra.zip`（内含 JSON + M3U）。
- 导入：`.lyra.zip`、TuneMyMusic 导出的 CSV / TXT、通用 M3U、Spotify/Apple Music CSV 导出（匹配本地曲库）。
- 匹配报告：成功 / 模糊匹配（需确认）/ 未找到，可对未找到项触发在线搜索与下载提示（**Lyra 不提供任何音乐下载功能**，只提示用户自行准备文件）。

## 11. 非功能

- 冷启动 <1.5s；1 万首曲库滚动 120Hz 不掉帧；常驻 <150 MB。
- 完全离线可用；在线功能失败静默降级。
- 深浅色 / 跟随系统 / 封面取色（Material You）；横屏；字体缩放。
- 中英双语。
- 隐私：不收集任何用户数据，无统计 SDK，无崩溃上报 SDK（崩溃日志本地保存，用户可手动导出）。
